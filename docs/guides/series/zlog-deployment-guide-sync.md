# Zlog 部署指南（二）：Turso 云端同步

上一篇说了三种方式的取舍，这一篇讲第二步：把博客数据同步到 Turso 云端库——本机照常使用（速度最快），云端是安全的备份与多端一致的数据源。

## 为什么需要同步

- **数据安全**：博客内容、图片、评论都存在本机。电脑坏了、误删目录，一切归零。同步后云端库就是实时备份。
- **多端一致**：台式机、笔记本各装一份 Zlog，填同一个连接串，内容自动保持一致。
- **为发布做准备**：Vercel 部署直接复用这套同步凭据，见第三篇。

## 第一步：注册 Turso 并创建数据库

1. 打开 [Turso](https://turso.tech) 注册（免费档对个人博客足够：几十万行数据、无限读取）。
2. 控制台点 **Create Database**，名称随意（如 `my-blog`），区域选离你最近的（如 Tokyo / Singapore）。
3. 创建后在数据库页拿到两样东西：
   - **URL**：形如 `libsql://my-blog-username.aws-ap-northeast-1.turso.io`
   - **Token**：点 **Generate Token** 生成一个读写（read/write）令牌，复制保存——它只在创建时显示一次。

## 第二步：在桌面端填入同步配置

1. 打开 Zlog 应用 →「设置 → 同步设置」。
2. 粘贴：
   - **数据库 URL**：`libsql://...` 连接串
   - **Token**：上一步生成的令牌
3. 点「保存并同步」——应用会立即做一次全量同步，之后每次写作、上传媒体、处理评论都会自动增量同步。

## 验证与日常

- 同步状态在设置页可见（最近同步时间/失败提示）。
- 换新电脑：装 Zlog → 填同一连接串 → 全部内容恢复。
- 想确认同步成功，可以到 Turso 控制台的 **Explore Data** 里看 `posts`、`media` 表是否有数据。

## 注意事项

- **Token 权限**：建议用读写令牌（要写入）；只读令牌会导致保存失败。
- **免费额度**：Turso 免费档有存储与行数上限（个人博客远用不完），超出前控制台会提示，不会突然停服。
- **离线**：本地库是嵌入式副本，断网也能写，联网后自动回同步。

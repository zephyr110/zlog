# Zlog 部署指南（一）：三种方式怎么选

Zlog 是一款自带后台的博客系统：桌面应用内置完整的 Web 服务与写作后台，你可以选择在本地使用、同步到云端数据库，或一键发布到公网。这篇是系列第一篇，帮你快速决定用哪种方式；后续两篇分别讲 [云端同步](zlog-deployment-guide-sync) 与 [一键发布 Vercel](zlog-deployment-guide-vercel)。

## 三种方式一览

| | **本地使用** | **本地 + Turso 同步** | **一键发布 Vercel** |
| --- | --- | --- | --- |
| 适合 | 私人笔记、本地预览 | 怕丢数据、多设备一致 | 公开网站、让别人访问 |
| 配置 | 零配置 | Turso 注册 + 连接串 | Vercel 注册 + Token |
| 数据在哪 | 本机 | 本机 + 云端库 | 云端库（Turso） |
| 博客能访问吗 | 仅本机 | 仅本机 | 所有人 |
| 上手难度 | ★☆☆ | ★★☆ | ★★★ |

## 决策树

1. **只想自己写、不想折腾** → 直接装桌面应用，本地开箱即用（见下文）。
2. **怕电脑坏了数据丢失，或想在多台设备写** → 加一步 Turso 同步，[看第二篇](zlog-deployment-guide-sync)。
3. **想把博客分享给任何人** → 在同步的基础上，用应用内「一键部署」发布到 Vercel，[看第三篇](zlog-deployment-guide-vercel)。

> 推荐路径：先本地用起来（5 分钟），再同步上云（10 分钟），最后想公开时一键部署（2-5 分钟）。每一步都是上一步的自然延伸，不需要重来。

## 快速开始：本地使用

1. 安装 Zlog 桌面应用（macOS / Windows），双击打开。
2. 首次启动自动完成初始化：在「设置 → 账号」里配置管理员账号，本地数据库随应用创建。
3. 点「打开后台」开始写作：Markdown、文章封面、标签、评论审核、媒体库、流量仪表盘一应俱全。

数据保存在本机用户数据目录（macOS 为 `~/Library/Application Support/@zlog`），完全离线可用；博客通过 `http://localhost:<端口>` 访问。

## 常见问题

**Q：免费够用吗？**
A：Vercel Hobby 与 Turso 免费档对个人博客（日均几百访问、几十篇文章）完全够用。

**Q：忘了后台密码？**
A：桌面端「设置 → 账号」重新生成恢复密钥，或重置本地配置重新初始化。

**Q：以后想换方式要重来吗？**
A：不用。本地 → 同步 → 发布是递进的，配置互不冲突，随时可以只做其中一步。

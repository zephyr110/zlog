# Zlog 部署指南（中文）

Zlog 是一款自带后台的博客系统：桌面应用内置完整的 Web 服务与写作后台，你可以选择在本地使用、同步到云端数据库，或一键发布到公网。本文按使用场景由浅入深介绍三种部署方式。

---

## 场景一：本地使用（开箱即用）

适合：只想自己写博客、不关心公网访问的用户。

**步骤：**

1. 安装 Zlog 桌面应用（macOS / Windows），双击打开。
2. 首次启动自动完成初始化：后台管理员账号在「设置 → 账号」中配置，默认本地数据库随应用创建。
3. 点击「打开后台」即可开始写作：支持 Markdown、文章封面、标签、评论审核、媒体库、流量仪表盘。

**特点：**

- 零配置，数据保存在本机（`~/Library/Application Support/@zlog` 下），完全离线可用。
- 博客只能本机访问（`http://localhost:<端口>`），适合私人笔记或本地预览。

---

## 场景二：本地 + Turso 云端同步（数据上云）

适合：担心本机数据丢失，希望文章在多个设备间一致的用户。

**步骤：**

1. 注册 [Turso](https://turso.tech)（免费额度足够个人博客），在控制台创建数据库，记录 `libsql://...` 连接串与 Token。
2. Zlog 设置 → 「同步设置」中粘贴：
   - 数据库 URL：`libsql://xxx.turso.io`
   - Token：控制台生成的只读/读写令牌
3. 点「保存并同步」——之后每次写作、上传媒体都会自动同步到云端库。

**特点：**

- 本地照常使用（速度最快），云端库是安全的备份与多端一致的数据源。
- 数据不丢失：换电脑后在新设备安装 Zlog，填同一连接串即可恢复全部内容。
- 注意：仅数据上云，博客页面仍未发布到公网。

---

## 场景三：一键部署到 Vercel（发布到公网）

适合：想把博客发布成公开网站、让别人能访问的用户。

**前提：** 已按场景二完成 Turso 同步配置（部署会把同步凭据一并写入线上环境）。

**步骤：**

1. 注册 [Vercel](https://vercel.com)，在控制台生成 API Token（Settings → Tokens → Create Token）。
2. Zlog 设置 → 「一键部署（Go Live）」面板：
   - 粘贴 Token
   - 项目名可留空（自动生成）或自定义
3. 点「部署」：应用自动完成 校验 Token → 创建项目 → 配置环境变量 → 上传代码 → 云端构建，约 2-5 分钟。
4. 完成后显示线上地址（形如 `https://你的项目名.vercel.app`），即可分享给任何人。

**特点：**

- 全程图形化，无需 Git、命令行或手动配置环境变量。
- 后台与站点共用同一套数据（Turso 云端库）：线上发布的文章、后台管理完全可用。
- 修改密码、写文章等后台操作与本地体验一致；媒体图片由应用自动处理（有 GitHub Token 走 CDN 加速，没有则直接从数据库提供，功能不受影响）。

## 可选：开启评论防垃圾（Cloudflare Turnstile）

评论默认直接可用（游客免登录）。要加人机验证防垃圾，需要 Cloudflare Turnstile 的两个 Key：

1. **注册 Cloudflare**（免费）：打开 [dash.cloudflare.com](https://dash.cloudflare.com) 注册。
2. **创建 Turnstile 站点**：控制台 **Turnstile → Add site**，Widget name 随意；**Hostname 填你的域名**（本地用 `localhost`，Vercel 部署填 `xxx.vercel.app`，多个逗号分隔）——密钥只对白名单域名生效（错误码 110200 = 域名未加白）。
3. **拿到两个 Key**：**Site Key**（公开）与 **Secret Key**（私密，创建时只完整显示一次，立即复制）。
4. **填入桌面端**：Zlog「设置 → 评论设置」粘贴两个 Key → 保存。本地评论立即显示人机验证；一键部署时自动透传，线上防护一致。

> 没配置时评论照常可用，只是没有验证码。Cloudflare 测试 key（`1x000...` 永远通过 / `2x000...` 永远拒绝）只用于本地调试，**不要部署到生产**。

## 常见问题

**Q：忘记后台密码怎么办？**
A：桌面端「设置 → 账号」中重新生成恢复密钥，或直接重置本地配置重新初始化。

**Q：如何开启评论防垃圾？**
A：桌面端「设置 → 评论设置」填入 Cloudflare Turnstile 的 Site Key 与 Secret Key（Turnstile 控制台创建站点即可获得）。本地评论即启用人机验证，一键部署时自动透传，线上防护一致。

**Q：Vercel 部署后如何更新代码？**
A：桌面端重新点「部署」即可覆盖线上版本（环境变量自动复用）。

**Q：免费额度够用吗？**
A：Vercel Hobby 与 Turso 免费档对个人博客（日均几百访问、几十篇文章）完全够用。
